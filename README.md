# QR Code 萬用工具箱 (QR Code Toolbox)

一個現代化、功能全面且支援高自訂性的 **QR Code 萬用工具箱**。提供深淺色主題切換、多種內容格式支援、即時掃描、短網址、圖片轉 QR 及批次大量產生打包。

## ✨ 主要特色與功能

1. **多元內容格式產生**
   - 🌐 **網址 (URL)**：支援一鍵產生，並內建智慧短網址縮短功能。
   - 📝 **純文字**：備忘錄、文字公告、序號。
   - 📶 **Wi-Fi 熱點**：輸入 SSID、密碼與加密類型，掃碼自動連接。
   - 📇 **電子名片 (vCard)**：姓名、電話、Email、職稱、公司資訊一鍵導入通訊錄。
   - ✉️ **電子郵件 (Email)**：自動填寫收件者、主旨與內容。
   - 📞 **電話與簡訊**：掃碼直接撥號或發送 SMS。
   - 💬 **社群帳號**：快速導向 LINE、Instagram、Facebook、YouTube 等。
   - 📍 **地圖導航**：輸入地址或經緯度直接開啟用 Google 地圖。

2. **精美外觀與深度客製化**
   - **碼點形狀**：經典方塊、圓形圓點、圓角方塊等。
   - **邊角形狀**：客製化定位角邊框與中心圖案。
   - **自訂色彩與漸層**：支援單色、線性漸層、徑向漸層與背景色彩調整。
   - **中心 Logo 標誌**：可上傳自訂圖片或企業 Logo 置於中心。
   - **高解析度匯出**：支援 PNG、SVG、JPEG 格式下載，並可調整輸出尺寸（500px ~ 2000px）。

3. **圖片轉 QR Code**
   - 支援將本機圖片快速轉換為 QR Code 展示或短網址。

4. **相機與圖片即時解碼 (Scanner)**
   - 支援裝置相機鏡頭即時掃描。
   - 支援拖曳或上傳 QR Code 圖片直接解析內容。

5. **批次大量產出 (Batch Generator)**
   - 多行內容快速匯入，一鍵大量產生。
   - 支援打包為 ZIP 檔案下載。

6. **歷史紀錄與友善體驗**
   - 記錄最近產生與掃描的內容，方便隨時重新取用。
   - 完美支援桌機與行動裝置，並提供舒適的深色（Dark Mode）與淺色（Light Mode）主題切換。

## 🚀 部署方式

本專案為純前端單頁應用（SPA），無需後端伺服器即可直接部署：

### Netlify 部署
1. 登入 [Netlify](https://app.netlify.com/)
2. 點擊 **Add new site** -> **Import an existing project**
3. 選擇 **GitHub** 並授權存取本倉庫 `yaoshuchin/qrcode-toolbox`
4. 保持預設設定（無需構建指令，Publish directory 為根目錄），點擊 **Deploy site** 即刻上線！
